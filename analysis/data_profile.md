# Data Profile

This project now contains six source-style datasets with 4154 total records.

## Table Roles

- `entities.csv` defines the operating surface.
- `daily_metrics.csv` gives enough history to inspect trend, volume, quality, and automation impact.
- `source_events.csv` explains why metrics move or become untrustworthy.
- `stakeholder_requirements.csv` keeps requirements tied to decisions and acceptance tests.
- `data_quality_checks.csv` makes QA visible instead of hiding it behind dashboard outputs.
- `recommended_actions.csv` converts findings into a sequenced action queue.
